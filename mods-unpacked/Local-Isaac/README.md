# 以撒角色与道具 · Local-Isaac 0.43.0

Brotato 1.2.0.1 非官方以撒主题模组，含 8 个角色、67 件道具、34 个武器品质条目和 8 个自定义套装。

0.43 新增山羊头、二元性、作孽双子、嗜血腥风，调整宠物与环绕加成；保留新版 DLC 兼容与魅惑资源修复。

## 安装与前置

当前版本通过原生接口注册内容，自带所需属性分页，没有第三方 Mod 必要前置，也未内嵌旧前置。

请按[仓库 README](https://github.com/fanfanfan91666/brotato-isaac)下载安装 ZIP、校验文件，以及同版本的 install.ps1 和 isaac-local-loader.gd；四个文件放在一起，退出游戏后运行安装脚本。保持本 ZIP 压缩状态，安装目标为游戏目录的 mods 文件夹。旧版的前置载体路径不再适用。

旧版需要的 [NewContentLoader](https://steamcommunity.com/sharedfiles/filedetails/?id=3657905142) 与 [MoreStatsContainer](https://steamcommunity.com/sharedfiles/filedetails/?id=3771724268) 只提供工坊链接，由用户自行下载，不随本项目分发。它们不是当前版本的安装要求。
