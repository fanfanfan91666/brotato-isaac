# 以撒角色与道具 · Local-Isaac 0.41.0

Brotato 非官方《以撒的结合》主题模组，包含 8 个角色、51 件道具、34 个武器品质条目和 7 个自定义武器套装。提供简体中文、繁体中文与英文。

0.41 正式开放死神之触（紫/橙）和命运之矛（蓝/紫/橙）：概率造成 2 秒恐惧，使敌人停止移动、受到的最终伤害增加 30%。死神之触发射旋转镰刀；新增战争套装，愤怒套装改为伤害和暴击率。

## 安装

1. 在 Steam 工坊订阅并下载 [NewContentLoader](https://steamcommunity.com/sharedfiles/filedetails/?id=3657905142) 与 [MoreStatsContainer](https://steamcommunity.com/sharedfiles/filedetails/?id=3771724268)，本版本适配两者 1.2.0、Brotato 1.1.15.4、Mod Loader 6.3.0。
2. 从[本仓库 Releases](https://github.com/fanfanfan91666/brotato-isaac/releases)下载 `Local-Isaac-0.41.0.zip`。Code 下载的源码 ZIP 和 Release 的 Source code 不能直接安装。
3. 等前置下载完成并退出游戏，把本 ZIP **保持压缩状态**放入该游戏所在 Steam 库的 `steamapps/workshop/content/1942280/3657905142/`，保留 Steam 原有文件，不覆盖前置。先移出手动安装的旧版 Local-Isaac ZIP。
4. 从 Steam 启动游戏，在 MOD 菜单确认 Local-Isaac、Yoko-NewContentLoader、Yoko-MoreStatsContainer 三项已启用，按提示重启。

在 Steam 中右键 Brotato → 管理 → 浏览本地文件，返回到 `steamapps`，再进入 `workshop/content/1942280/3657905142/`。例如 D 盘 Steam 库为 `D:/SteamLibrary/steamapps/workshop/content/1942280/3657905142/`；C 盘常见位置为 `C:/Program Files (x86)/Steam/steamapps/workshop/content/1942280/3657905142/`。应使用游戏所在的同一个 Steam 库。不要解压模组 ZIP，不要放入游戏目录的 `mods` 文件夹，不附带前置。NewContentLoader 需保持订阅且已下载，手动建立数字文件夹不能使 Steam 挂载它。
